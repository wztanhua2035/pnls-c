# 《坡南龙蛇》AI 武侠 MUD

一个可直接部署到 Zeabur 的自适应网页游戏。玩家使用“男主角姓名 + 六位数密码”进入独立存档，剧情由后台调用 OpenAI 兼容模型实时演算。

## 功能

- 四选一与自然语言自由行动双模式
- 玩家继续游戏、重新开始、手动保存与退出前保存选择
- 手机、平板和电脑自适应的羊皮纸风格界面
- 独立的 `game-settings.json`，可修改世界观、地图、人物、道具和 AI 规则
- 管理后台 `/admin`：查看账号、游戏时长，修改管理密码
- 可添加多条 OpenAI 兼容 API 配置，并选择当前生效模型
- API Key 使用 AES-256-GCM 加密后存储；玩家密码使用 scrypt 单向散列
- 只依赖 Node.js 20+，数据保存在 JSON 文件中
- AI剧情支持真实流式接收和逐字显示，剧情完成后才更新四个选项与人物状态
- 每轮只发送相关地区资料、最近5回合原文和长期摘要，减少无关提示词
- 尚未登场的女主不会显示在人物关系栏，旧存档会自动兼容新结构

## 本地运行

```bash
cp .env.example .env
# 按需加载 .env，或直接设置其中的环境变量
npm start
```

浏览 `http://localhost:3000`，管理后台为 `http://localhost:3000/admin`。

如果未设置环境变量，初始管理密码为 `pnls-admin-2026`。正式上线前务必设置 `ADMIN_PASSWORD` 和至少 32 位随机 `APP_SECRET`，登录后台后也可修改管理密码。

## 部署到 Zeabur

1. 将本项目文件夹上传到 GitHub，或在 Zeabur 选择“上传/部署本地项目”。
2. Zeabur 会读取 `Dockerfile` 启动服务，端口由 `PORT` 自动适配。
3. 添加一个持久化卷并挂载到 `/data`，否则服务重建后玩家存档和模型配置会丢失。
4. 在环境变量中设置：

   - `ADMIN_PASSWORD`：首次启动的后台密码
   - `APP_SECRET`：至少 32 位随机字符串，后续不要更换，否则已保存的 API Key 无法解密
   - `DATA_DIR=/data`

5. 部署完成后进入 `/admin`，添加至少一条 AI 模型 API 并启用。

也可通过 `AI_NAME`、`AI_BASE_URL`、`AI_MODEL`、`AI_API_KEY` 在首次启动时自动创建默认模型配置。接口须兼容 OpenAI 的 `POST /chat/completions` 请求与响应格式。

## 修改基础设定

编辑 `game-settings.json` 后重新部署即可。它包含开场、地理、主线、三件神器、女主登场回合、好感度、叙事尺度和 AI JSON 输出格式。

当前叙事长度规则为：普通回合100至200字，重大剧情200至500字。地图资料按 `world.geographyRegions` 中的关键词与当前位置动态选择；每个地区可独立修改关键词和说明。

## 从旧版本升级

覆盖代码并重新部署即可，现有 `/data` 数据卷不需要删除。旧存档第一次登录时会自动补充长期摘要和已登场女主字段。升级前仍建议先备份数据卷；不要删除或覆盖 `/data/accounts.json`、`/data/admin.json`、`/data/models.json`。

## 存档说明

AI 每轮生成的结果先保留为当前会话中的“未保存进度”。点击“保存进度”或“保存并退出”才写入持久化文件。浏览器不允许网页自定义关闭标签页时的弹窗文字，因此存在未保存进度时，系统会显示浏览器原生的离开确认提示；建议通过页面内“退出游戏”选择是否保存。

## 数据与安全

- `data/accounts.json`：账号、累计时长与游戏存档
- `data/admin.json`：管理密码散列
- `data/models.json`：AI 模型配置和加密密钥
- 不要把运行后的 `data/*.json`、`.env` 或 API Key 提交到公开仓库
- 本项目适合个人、小团队体验；若面向大量公开用户，建议改用 PostgreSQL，并增加限流、验证码、审计日志和备份
