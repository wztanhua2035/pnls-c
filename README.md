# 来玩泥巴｜AI MUD 游戏集合

一个可直接部署到 Zeabur 的多游戏 MUD 网站。首页展示当前开放的游戏；玩家进入游戏介绍页后，可开始新游戏或继续个人存档。所有游戏共用后台启用的 OpenAI 兼容模型。

## 主要功能

- 首页16:9题头图与可玩游戏列表
- 每个游戏独立的题头图、简介、规则和玩家存档
- 游戏简介页显示100至150字的背景及前置情节说明
- 先以6位字母数字用户名和6位数字密码验证，再设置本游戏允许自定义的主角元素
- 后台表单添加、编辑、暂停、恢复和删除游戏
- 题头图片支持16:9 PNG、JPG、WebP上传；不上传时使用与 `index.html` 同目录的 `gomudbanner.png`
- 默认采用高自由度、主角视角、前20回合新手豁免和每回合四个选项
- 默认采用主角有限视角；陌生人物的姓名、身份和秘密必须经由观察、交谈或调查获得
- 固定选项与自然语言自由行动并存
- 普通回合100至200字，重大剧情200至500字
- 剧情流式接收并逐字显示，完成后再显示选项与状态
- 每轮只发送最近5回合、长期摘要、当前状态和相关背景资料
- 游戏正文支持小、中、大字号和加粗，选择保存在当前浏览器
- 全站适配手机、平板和电脑

## 部署到 Zeabur

1. 用本目录中的全部文件覆盖 Git 仓库原项目文件并提交。
2. 保留原有 `/data` 持久化数据卷，挂载路径仍为 `/data`。
3. 保留现有环境变量：

   - `DATA_DIR=/data`
   - `ADMIN_PASSWORD`：首次启动使用的管理密码
   - `APP_SECRET`：已有模型密钥的加密密钥，升级时绝对不要更换

4. 等待 Zeabur 自动重新部署。
5. 打开网站后按 `Ctrl+Shift+R` 强制刷新一次。

部署成功时日志显示：

```text
来玩泥巴已启动：http://0.0.0.0:3000
```

管理后台地址为 `/admin`。原有 AI 模型配置会继续保留。

## 从《坡南龙蛇》旧版升级

旧版 `/data/accounts.json` 会在玩家首次登录时自动迁移为多游戏存档结构；原有《坡南龙蛇》会自动成为游戏大厅中的第一个游戏。无需删除数据卷，也不要覆盖以下文件：

- `/data/accounts.json`
- `/data/admin.json`
- `/data/models.json`

新文件 `/data/games.json` 保存游戏配置，`/data/banners/` 保存后台上传的题头图片。建议升级前备份整个 `/data` 数据卷。

## 数据与安全

- 玩家密码使用 scrypt 单向散列。
- AI API Key 使用 AES-256-GCM 加密。
- 生产环境务必使用至少32位的随机 `APP_SECRET`。
- 本项目适合个人或小团队运营；大规模公开运营建议改用数据库，并增加限流、验证码、审计和自动备份。
